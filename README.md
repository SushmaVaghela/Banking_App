# HSBC Banking Website Automation – Cypress

## Project Overview
An end-to-end web automation testing project developed during my internship with Fortray. The project focuses on automating key banking website functionalities to support efficient and consistent testing.

## Objectives
- Automate important user journeys.
- Validate application functionality.
- Support regression testing and reduce repetitive manual testing.

## Technologies & Tools
- **Automation Framework:** Cypress.io
- **Programming Language:** JavaScript
- **IDE:** Visual Studio Code
- **Version Control:** Git & GitHub

## Key Features
- **Login Automation:** Validate login interactions and authentication behaviour.
- **ATM Search Automation:** Automate location searches and validate results.
- **Credit Card Automation:** Validate credit card navigation and displayed information.

## My Role & Contributions
- Analysed application workflows and identified automation scenarios.
- Developed Cypress test scripts using JavaScript.
- Implemented element interactions and assertions.
- Reviewed application changes and documented observations with screenshots.

## How to Run
1. Install [Node.js](https://nodejs.org/).
2. Clone the repository.
3. Run `npm install`.
4. Launch Cypress using `npx cypress open`.
5. Alternatively, execute tests using `npx cypress run`.
